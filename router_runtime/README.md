# 家庭语音路由计算

在虚拟机中运行路由分类、错别字纠正与 Kokoro 中文语音。模型从“家庭助手 → 设置 → 模型管理”选择下载。源码与镜像不含模型，路由分类头需先填写独立 Release 附件地址。

应用不需要 HA 令牌、DeepSeek API 或千问 API。端口 17861 仅供 HA 内部容器通信，未映射到主机；请勿将它直接暴露到公网。调用设备和存储个人习惯由 HA 集成负责。

持久化 `/data/models` 保存下载模型。应用备份会包含持久化数据；卸载应用可能删除模型数据，请先备份。版本更新使用“更新”，同版本源码修改可用“重建”，均不删除 `/data`。

CPU 默认为 2 线程；可在统一设置选择 1–4 线程。本地 Kokoro 按完整回复生成，首次使用有加载时间。FP16 减少磁盘用量，不保证在 CPU 上提速。

模型来源与许可证见仓库 `THIRD_PARTY_NOTICES.md`。
